# Android app

The Android app is the same React codebase running in a [Capacitor](https://capacitorjs.com/) native shell. There is no second codebase: `npm run build` produces the web bundle, and Capacitor packages it into an APK/AAB.

The native `android/` directory is **generated, not committed** (see `.gitignore`). Regenerate it with `npm run android:add`.

## Get an APK without installing anything

Push the branch and open the **Actions → Android build** run. It generates the native project and uploads an installable debug APK as the `aurelix-debug-apk` artifact.

## Build locally

Requires Node 20, **JDK 17** (Capacitor 6 and the Android Gradle Plugin reject newer JDKs), and the Android SDK — normally via Android Studio.

```bash
npm ci
npm run android:add     # one-time: generates android/ and applies permissions
npm run android:apk     # build web bundle, sync, assemble debug APK
```

Output: `android/app/build/outputs/apk/debug/app-debug.apk`

Day-to-day, after changing web code:

```bash
npm run android:sync    # rebuild web bundle and copy into the native project
npm run android:open    # open in Android Studio to run on a device/emulator
```

## Required configuration before release

These need access to your Firebase and Razorpay consoles, so they are not in the repo.

### 1. Firebase Android app

The app id is `com.aurelix.parallax` (`capacitor.config.json`). In the Firebase console, register an Android app with **exactly that package name**, download `google-services.json`, and place it at `android/app/google-services.json`.

Because `android/` is regenerated, copy it in after `android:add` — or commit `android/` once the project stabilises.

### 2. Google sign-in

`signInWithPopup` cannot work inside a WebView, so `src/lib/googleSignIn.ts` picks a strategy per platform:

| Platform | Strategy |
| --- | --- |
| Web | `signInWithPopup` |
| Android + `@capacitor-firebase/authentication` installed | Native Google account picker, then `signInWithCredential` |
| Android without that plugin | `signInWithRedirect` fallback |

The redirect fallback works but is fragile in a WebView. **For production, install the native plugin:**

```bash
npm i @capacitor-firebase/authentication
npm run android:sync
```

You must also register your app's **SHA-1 fingerprint** in the Firebase console, or the native Google sign-in returns a `DEVELOPER_ERROR`:

```bash
cd android && ./gradlew signingReport   # copy the debug SHA-1
```

Add `localhost` to **Firebase Auth → Settings → Authorized domains**; with `androidScheme: "https"` the WebView origin is `https://localhost`.

### 3. Payments

The wallet loads Razorpay Checkout from a remote script. It runs in the WebView, but Razorpay's supported Android path is their native SDK — verify checkout on a real device before release.

`upi://` links are handed to the OS via `openExternalUrl()` in `src/lib/native.ts`; an in-WebView anchor is silently dropped. For `AppLauncher.canOpenUrl()` to work on Android 11+, add a `<queries>` element to the manifest.

## What the native layer changes

| Concern | Where | Why |
| --- | --- | --- |
| Hardware back button | `src/components/native/NativeShell.tsx` | Without a handler, Capacitor closes the app on any back press instead of navigating back |
| Status bar + splash | `applyNativeChrome()` in `src/lib/native.ts` | The splash is configured not to auto-hide, so it must be dismissed after mount |
| External / `upi://` links | `openExternalUrl()` | The WebView cannot resolve non-http schemes |
| Camera, mic permissions | `scripts/configure-android.mjs` | `cap add android` only grants `INTERNET`; live streaming, calls and capture need more |

Everything in `src/lib/native.ts` reaches Capacitor through the `window.Capacitor` global rather than static imports, so all of it is a no-op on the web and the project type-checks without the native packages installed.

## Not yet verified

- No APK has been produced from this branch. It was written in an environment with no network access and no Android SDK, so `npm ci`, `vite build` and Gradle could not run. The CI workflow is the first real build.
- `scripts/configure-android.mjs` is tested against a representative manifest (idempotent, no duplicates, well-formed output), but not against a manifest generated by your Capacitor version.
- Camera/mic permissions are declared in the manifest. Android also requires a **runtime** prompt; if `getUserMedia` is rejected on device, add a permissions plugin and request before starting a stream or call.
